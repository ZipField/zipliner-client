# 账号与定位接入

## 更新兼容

首次启动会将原来的本机账号列表迁入本地游客档案，保留账号 ID、区服、标签和当前角色，并将该角色作为游客默认角色。已有账号的用户会自动进入本地模式。

档案写入系统安全存储后会回读核对；旧凭据键不会删除，也不会自动上传到 Zipliner。迁移失败时显示重试，不会按空账号列表继续运行。请勿清除应用数据。

## 使用

- 首页可以登录 Zipliner 或选择本地模式。切换模式不会删除另一个模式的数据。
- Zipliner 模式的账号管理与网站绑定同步，支持绑定、重新认证、改名、移除、设置默认账号和角色。本机当前角色单独保存。
- 账号卡片点击后打开详情面板，面板内选择当前角色、设置默认账号和默认角色，以及重新认证或移除账号。
- 登录 Zipliner 后，账号管理最上方的全宽按钮可切换“Zipliner 绑定账号”和“本机账号”。未登录时只显示本机账号，没有切换按钮。重连过程中账号管理保持可用。
- 选用本机角色会直接连接森空岛 / SKPort，无需退出 Zipliner，无需重复添加游客档案已有的凭据。旧测试版本单独保存的本机直连凭据也会合并保留到本地档案。
- 选用 Zipliner 绑定角色或本机角色时均在客户端直连。绑定角色的直连凭据首次获取后按 Zipliner 用户隔离存入系统安全存储，独立于游客档案。
- 不再提供自动直连兜底或自动切回。网站订阅实时位置时，由已登录客户端独立上传坐标；后台失败不影响本机直连。
- 已移除主动刷新开关和 0.2–10 秒请求速度设置。位置由服务端推送，保留首次订阅和协议心跳。
- “设置 → 地图名称与高度配置”可查看地图、区域名称和限高限低。未设置的值显示“无”；缺少或无法读取的配置另行提示。
- Windows 上首次连接和手动重连不受游戏窗口限制；拿到坐标就正常显示。后续自动重连失败且没有游戏窗口时，暂停自动重连并显示“请打开终末地游戏”。发现游戏窗口后等待 30 秒再自动重试；等待和重连时账号管理仍可操作。

## 后端配套

客户端上传连接使用 `/hubs/data`；坐标首先在本机显示。有网站订阅才上传变化，静止时 10 分钟补发一次。连续 30 秒未收到官方坐标消息才判定本机直连断开。后台上传连接意外断开时网站退出实时位置，不自动抢占客户端上游。

本次后端增加坐标流标识、序号、观测时间及快照标记，客户端过滤重复和历史快照。地图名称及高度配置缓存于本机；从未获得过配置时仍视为未知，不会擅自认定为无限制区域。

云端账号改名使用新接口 `/api/account/game-accounts/label`，需要配套后端部署后可用。源码修改不等于线上后端已更新。
