# 独立坐标窗口

坐标页面通过“在悬浮窗显示坐标”开关控制坐标显示。使用快捷键或关闭坐标显示时，
开关状态会同步更新；弱网页面的“在悬浮窗显示弱网状态”独立控制弱网状态显示。
关闭坐标显示不会隐藏仍需显示的弱网状态，两项均不显示时悬浮窗隐藏。
程序会记住开关状态，下次启动时自动恢复。正常退出程序不会更改这项选择。

主界面始终保留自己的窗口。坐标窗由同一可执行文件的 `--coordinate-window`
显示模式启动，在独立进程中运行 Flutter 界面，不获取账号凭据、不订阅坐标接口、
不初始化弱网控制器，也不注册全局快捷键。

主程序通过随机端口的 IPv4 回环连接发送坐标、识别结果和显示偏好。
连接以每次启动生成的随机凭证验证。子进程只在内存中保存显示偏好，
不会覆盖主程序的设置或账号存储。

Windows 坐标窗使用工具窗口样式，因此不单独占用任务栏；显示、置顶、移动均不激活窗口。
跟随模式只读取游戏窗口位置，鼠标穿透。主窗口和游戏窗口处于前台时保留坐标窗，
切换到其他应用超过一秒后隐藏。

F12（可设置）由主程序响应，控制坐标窗的打开与关闭。子窗口请求返回时，
主程序关闭坐标窗并显示主界面。主进程退出或回环连接断开时子进程自行退出；
主动关闭超时两秒时，主程序只终止其创建的显示进程。

坐标显示与弱网状态独立控制。关闭坐标显示后，如果弱网状态仍需显示，保留同一个
显示进程并只显示弱网状态行。两项均无需显示时才退出显示进程。
弱网开启、关闭、计时及暂时解除提示均由主程序同步，不在显示进程初始化网络控制器。

独立显示进程会增加一份 Flutter 引擎的内存开销，未增加新的原生插件或运行时依赖。
当前改动只经过静态检查和编译；任务栏、DPI、多屏、跟随与退出行为仍需 Windows 实机验证。
