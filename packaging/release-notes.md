# Zipliner Client 0.2.0

本次更新将原坐标工具整合为 Zipliner Client，新增 Zipliner 账号、共享定位与 Windows 自动弱网功能，并重新整理账号管理和悬浮窗。

## 账号与实时定位

- 首页可登录 Zipliner，也可选择本地游客模式；旧版本机账号会自动迁入本地游客档案，账号和角色选择会保留。
- 登录 Zipliner 后，可管理网站绑定的森空岛 / SKPort 账号、切换当前角色并设置默认账号与角色。
- 账号管理中可切换网站绑定账号与本机账号；使用本机账号不需要退出 Zipliner。
- Zipliner 共享定位支持与网站同时使用；本机账号仍可直接连接森空岛 / SKPort。
- 森空岛登录支持扫码和验证码，保留 SKPort 登录，移除森空岛密码登录。
- 定位异常时直接显示错误说明，并支持手动重新连接。未打开游戏时暂停频繁自动重试，检测到游戏窗口后等待 30 秒再自动连接。

## 悬浮窗与地图信息

- 坐标悬浮窗改为独立窗口，主界面保持可用。
- 坐标与自动弱网状态可分别选择是否显示，并记住显示设置。
- 支持选择其他游戏窗口，默认使用 Endfield.exe；切换窗口时同步切换弱网目标程序。
- 地图信息显示为“地图 / 区域”名称，新增地图名称与限高、限低查看入口；未设置高度限制时显示“无”。
- 保留目标坐标、距离显示与滑索采集，移除“蹭缝”功能。

## Windows 自动弱网

- 新增自动弱网，根据游戏网络流量和当前坐标辅助识别，需先连接坐标才能开启。
- 支持“暂时解除弱网”和“连接游戏”；默认快捷键为 Ctrl+· 开关功能、Ctrl+Tab 暂时解除弱网，均可修改。
- 最大弱网时长可设为 10–30 秒，默认 20 秒；暂时解除后重新计时。
- 每次启动后首次启用须确认风险并允许管理员权限；首次使用须等待 5 秒才能确认，后续启动不再倒计时。
- 新增网络驱动被安全软件阻止时的处理提示；退出时显示“正在退出…”，并清理连接和网络驱动。

自动识别仍可能误判或遗漏解除。请仅在需要弱网的场景开启，常规游戏期间关闭，发现异常及时暂时解除或关闭功能。受游戏客户端限制，无法依靠本功能在区域内持续停留超过约 30 秒。弱网操作存在风险，不代表官方许可，也不能保证今后安全。

## 升级与下载

| 设备 | 下载文件 |
| --- | --- |
| Windows 电脑 | `zipliner-client-{{VERSION}}-windows-x64.zip` |
| 安卓手机 / 平板 | `zipliner-client-{{VERSION}}-android.apk` |
| Linux 电脑 | `zipliner-client-{{VERSION}}-linux-x64.tar.gz` |

- Windows 和 Linux 请先完全退出旧版本，再解压新版本；不要在压缩包中直接运行。账号和设置会保留，无需删除旧数据。
- Android 请使用相同来源、相同签名的新 APK 覆盖安装；不要为升级清除应用数据。
- 自动弱网目前仅支持 Windows；Android 和 Linux 可使用账号、坐标等对应平台支持的功能。
- Windows 当前版本存在屏幕阅读器控件识别限制；该兼容性处理用于规避已知启动崩溃。
- 首次使用可查看“设置 → 使用帮助”；反馈问题时可附上“设置 → 复制诊断信息”。
- `SHA256SUMS.txt` 提供下载文件的校验值。
