## 下载哪个文件？

| 你的设备 | 下载 | 怎么用 |
| --- | --- | --- |
| **Windows 电脑**（绝大多数人选这个） | `zipliner-client-{{VERSION}}-windows-x64.zip` | 右键 → 全部解压缩，打开解压出来的文件夹，双击 `zipliner_client.exe` |
| **安卓手机 / 平板** | `zipliner-client-{{VERSION}}-android.apk` | 用手机下载后点开安装，提示“未知来源”时选择允许 |
| Linux | `zipliner-client-{{VERSION}}-linux-x64.tar.gz` | 解压后运行 `zipliner_client`，需要系统已安装 GTK3 与 libsecret |

- 不要直接在压缩包里双击运行，一定要先**解压**。
- Windows 提示“Windows 已保护你的电脑”：点“**更多信息**” → “**仍要运行**”（本工具没有购买代码签名证书）。
- **升级**：下载新版本后解压覆盖旧文件夹即可，账号和设置都会保留；安卓直接安装新 APK 覆盖。
- 第一次使用请看应用里的“设置 → 使用帮助”。

`SHA256SUMS.txt` 是各文件的校验值，可用来确认下载完整。
