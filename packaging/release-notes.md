# Zipliner Client {{VERSION}}

本次更新重整客户端内部结构，并改进定位连接、账号会话、启动和退出流程。

## 定位与账号

- 客户端直连定位令牌按账号和角色复用。普通断线及 `19001` 恢复时沿用缓存；只有官方服务返回 `10002` 才清除令牌并重新领取。每次 `10002` 都会继续刷新并按退避间隔重连。
- 账号凭据、角色和政策状态在客户端会话内复用，重连不重复执行账号登录和角色初始化。账号凭据轮换或重新登录时清理对应缓存。
- 客户端直连定位与 Zipliner 网站坐标转发分开管理。网站连接或上传失败不会中断本机定位；坐标变化时上传最新状态，并合并等待中的更新。
- 定位采集和实时事件处理拆分为独立模块，延迟返回的数据不会覆盖新连接的状态。

## 启动、退出与弱网

- 启动时先显示进度界面，再初始化设置和服务；初始化失败时可重试。账号资料恢复在后台进行，期间仍可使用本地账号。
- 退出时显示清理进度，等待定位、弱网辅助程序和坐标子窗口完成关闭后再关闭主窗口。
- Windows 弱网辅助程序拆分为网络引擎、坐标判定、数据流和进程管理模块；保留原始 TCP 数据转发，并改进释放积压数据和资源清理流程。
- 增加网络辅助程序业务测试和定位恢复测试，覆盖令牌复用、重试、账号切换与异步清理行为。
